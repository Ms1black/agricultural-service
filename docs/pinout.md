# Распиновка устройства

Плата — ESP32-S3 DevKitC-1 (модуль **N16R8**: 16 МБ flash, 8 МБ PSRAM).
Пины в прошивке: `firmware/autopoliv_ui/autopoliv_ui.ino` (раздел «Пины», класс `LGFX`)
и `firmware/autopoliv_ui/audio_out.h` (звук). Менять пины — только вместе с этим файлом и PLAN.md (раздел 2).

## Не использовать

| GPIO | Почему |
|---|---|
| 0, 3, 45, 46 | strapping-пины: влияют на загрузку |
| 19, 20 | встроенный USB (разъём «USB») |
| 43, 44 | UART0 — разъём «COM», монитор порта (`Serial`) |
| 35, 36, 37 | **N16R8:** заняты PSRAM (octal) |
| 26–32 | flash и PSRAM внутри модуля |
| 15, 16 | плохо контактируют с макетом — только после проверки |

## Подробности подключения

**I2C (AHT20 + BH1750).** Оба модуля параллельно на GPIO 8 / 9, у каждого свой адрес — конфликта нет.
Подтяжки SDA/SCL уже стоят на модулях. Если датчик не найден, в мониторе порта будет
«AHT20 не найден» / «BH1750 не найден», прошивка работает без него. Если у BH1750 ADDR подключён к 3V3,
адрес станет 0x5C — прошивка его не найдёт.

**MAX98357A.** Звук на устройстве включён по умолчанию (`AUDIO_OUT = AUDIO_I2S_MAX98357` в `audio_out.h`).
Только в браузер — собрать с `-DAUDIO_OUT=AUDIO_NONE`. Динамик — только к OUT+ / OUT− усилителя,
не на GND и не к GPIO.

**Лампа досветки (GPIO 18).** Включается, когда света меньше 300 лк, выключается при больше 600 лк,
не чаще раза в минуту; без BH1750 выключена. Светодиоды подключены без резистора, поэтому драйвер пина
ограничен до минимума (`GPIO_DRIVE_CAP_0`, ~5 мА). Тускло — `GPIO_DRIVE_CAP_1` в `setup()`, сильнее не
ставить. Надёжнее — резистор 100–150 Ом последовательно. Пороги — `LAMP_ON_LUX` / `LAMP_OFF_LUX`.
BH1750 лучше направить так, чтобы лампа не светила прямо в него.

## Разъёмы USB и COM

| Разъём | Что это | На Mac |
|---|---|---|
| **COM** | переходник USB-UART → GPIO 43/44 | `/dev/cu.usbserial-…` / `/dev/cu.wchusbserial…` |
| **USB** | встроенный USB ESP32-S3 → GPIO 19/20 | `/dev/cu.usbmodem…` |

Подключать в **COM**: через него и прошивка (`pio run -t upload`), и монитор порта
(`pio device monitor`). Зависло на `Connecting...` — зажать BOOT, нажать и отпустить RST, отпустить BOOT.
