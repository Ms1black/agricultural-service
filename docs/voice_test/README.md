# Тестовый набор голоса (метрики 6.5)

Нужно ≥ 30 фраз, записанных живым голосом в условиях стенда (микрофон устройства или ноутбука).

1. Записать фразы: разные голоса, тихо и громко, с «Джарвис» и без; примерно поровну
   просьб полить (`water`), вопросов о растении (`status`) и прочего (`chat`).
2. Перевести в WAV 16 бит, моно, 16 кГц: `ffmpeg -i in.m4a -ac 1 -ar 16000 01.wav`.
3. Описать в `phrases.csv` (пример — `phrases.example.csv`): `file,text,intent`.
4. Запустить при работающем сервисе:
   `cd server && python scripts/voice_eval.py --server http://<IP>:8000 --token <PLANT_TOKEN>`
5. Результат — `results.md` (задержка медиана/p90, точность намерения, WER).

Фразы «полей» действительно просят полив через слой безопасности — запускать при влажной
почве или без подключённого устройства.
