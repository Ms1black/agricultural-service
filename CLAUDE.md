# Правила для ИИ-агентов

Проект: ПАК ухода за комнатными растениями с применением ИИ (ESP32-S3 + сервис на FastAPI).
Полный план, контракты API и лимиты безопасности — в [PLAN.md](PLAN.md). Этот файл — копия раздела 9.

Структура:
- `firmware/` — прошивка (PlatformIO: `cd firmware && pio run`). Секреты — `firmware/autopoliv_ui/secrets.h` (шаблон `secrets.example.h`).
- `server/` — сервис (`cd server && pip install -r requirements-dev.txt && pytest && ruff check .`).

## Правила

1. Нет доступа к железу. Прошивка обязана собираться в CI. В PR — «Ручная проверка».
2. Эталон — текущая прошивка. Поведение сохранять; рефакторинг — малыми шагами.
3. Распиновку не менять; не использовать GPIO 0, 3, 15, 16, 19, 20, 45, 46 без подтверждения человека.
4. Все `analogRead`/АЦП — под `adcMutex`.
5. Контракты раздела 4 не ломать; новые поля — только с обратной совместимостью.
6. Лимиты раздела 5 не ослаблять; любое их изменение — с тестами и пометкой в PR.
7. Секреты не коммитить (Wi-Fi, ключи LLM, `PLANT_TOKEN`, пароли).
8. Дисплей — латиница; веб и голос — русский.
9. ML: разбиение по времени, обязательное сравнение с бейзлайном, без улучшения — не выкатывать.
10. Один PR — одна задача из раздела 7; после слияния — отметить пункт в PLAN.md.

### Разделение агентов

| Агент | Зона | Задачи |
|---|---|---|
| **firmware** | `firmware/` | F1, F2, V2, часть V3, D1 |
| **server** | `server/app/{api,db,decision,voice,llm,web}` | S1, L1, V1, D0, часть V3, D1 |
| **ml** | `server/app/ml`, `ml/` | M1, M2 |

Изменения контрактов (раздел 4) — только через правку этого файла в том же PR.
